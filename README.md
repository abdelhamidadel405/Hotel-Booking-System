🏨 Hotel Booking System — Software Testing & QA Project

A Digital Egypt Pioneers Initiative (DEPI) graduation project focused on software engineering, quality assurance, and testing.

📌 Project Overview

The Hotel Booking System aims to simplify hotel reservations by providing user management, room availability, booking operations, customer records, and administrative reports. The project applies software testing principles to evaluate functionality, identify defects, and improve software quality.

🎯 Key Features

- User Management: Registration, login, logout, and profile management.
- Room Management: Add, edit, delete, search, and view rooms.
- Booking Management: Create, modify, cancel, and view reservations.
- Customer Management: Add, edit, search, and view customer records.
- Reports & Dashboard: Booking reports, room reports, and statistics.

🛠️ Tools & Technologies

- Programming Language: Java
- Database: SQL
- API Testing: Postman
- Automation Testing: Selenium WebDriver
- Version Control: Git & GitHub

All team members collaborate on:
